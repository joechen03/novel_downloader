# 通用小說下載器

輸入小說的**目錄頁網址**，自動找出所有章節並下載成一個 txt 檔。不針對特定網站撰寫規則，大部分「目錄頁 + 章節頁」結構的小說網站都能直接使用。

## 功能

- **自動判斷目錄**：找出章節連結並依順序排列，自動排除「最新章節」、導覽列、推薦書等雜訊。頁面上有「查看完整章節目錄」之類的按鈕時會自動點開；目錄拆成多頁時會自動抓回其他頁。
- **自動擷取正文**：找出頁面中的正文區塊，過濾常見廣告行與正文開頭重複的標題。
- **簡轉繁**：用 OpenCC 把殘留的簡體字轉成台灣正體，並把 “ ” ‘ ’ 換成「 」『 』。
- **一章多頁**：章節被拆成 `123.html`、`123_2.html` 時會自動合併。
- **快速模式**：在瀏覽器內同時下載多章，沒有限速的網站幾秒內就能下載完一整本。
- **Cloudflare 驗證**：遇到人機驗證時會跳出瀏覽器視窗，讓你手動完成驗證後自動繼續，並自動降速。
- **中斷續傳**：每下載一批章節就存進暫存，中斷（當機、關掉視窗、Ctrl+C）後重新執行同一個指令，會自動略過已下載的章節。連載中的小說之後再執行一次，也只會下載新章節。
- **品質檢查**：下載完會列出可疑的章節（字數過少或過多、和其他章內容重複），方便發現網站錯誤或抓錯頁面。
- **記住網站速度**：被限流的網站會記下穩定的速度，下次直接用這個速度開始，不必重新試探。
- **沒有目錄也能下載**：給章節網址時，會一路點「下一章」往下抓。

## 安裝

需要 Python 3.10 以上，以及已安裝的 Google Chrome。

```bash
pip install -r requirements.txt
```

不需要另外下載 chromedriver（Selenium 會自動處理）。

簡轉繁需要 `opencc`（已包含在 requirements.txt）。如果你的 Python 版本裝不起來，可以改裝純 Python 版 `pip install opencc-python-reimplemented`，用法相同。沒裝的話程式仍可執行，只是不會轉換簡體字（引號仍會轉換）。

## 使用方式

```bash
# 下載整本（檔名預設為「書名_網站名.txt」，例如「術師手冊_黃金屋.txt」）
python novel_downloader.py https://uukanshu.cc/book/17472/

# 先列出章節清單確認，不下載
python novel_downloader.py https://uukanshu.cc/book/17472/ --list

# 只下載第 1～100 章，並指定檔名
python novel_downloader.py https://uukanshu.cc/book/17472/ --end 100 -o 術師手冊.txt

# 中斷後：重新執行同一個指令即可，已下載的章節會自動略過
python novel_downloader.py https://uukanshu.cc/book/17472/

# 品質檢查標出第 173 章有問題，重新下載這一章
python novel_downloader.py https://uukanshu.cc/book/17472/ --start 173 --end 173 --refresh

# 沒有目錄頁：從某一章開始一路抓「下一章」
python novel_downloader.py https://example.com/book/1/1.html --mode next
```

### 參數一覽

| 參數 | 說明 |
|---|---|
| `url` | 目錄頁網址（`--mode next` 時為起始章節網址） |
| `-o`, `--output` | 輸出檔名，預設為「書名_網站名.txt」 |
| `--list` | 只列出章節清單，不下載 |
| `--start N` / `--end N` | 下載範圍。輸出的 txt 一律包含**所有已下載的章節**，不只這次的範圍 |
| `--refresh` | 重新下載範圍內的章節（預設會略過已下載的章節） |
| `--reverse` | 目錄由新到舊排列時使用 |
| `--mode auto/toc/next` | `auto` 自動判斷（預設）、`toc` 強制解析目錄、`next` 一路點下一章 |
| `-c`, `--concurrency` | 快速模式同時下載數，預設 8 |
| `--batch-size` | 快速模式每批幾章，預設 50；每批完成就存進暫存 |
| `-r`, `--rate` | 起始速度（每秒幾頁）。預設沿用上次記錄的速度，沒有記錄則不限；`0` 表示不限。被限流時自動降速，順利時再逐步加速 |
| `--slow` | 改用瀏覽器逐章開啟（需要執行 JavaScript 才有內容的網站使用） |
| `--show` | 下載時顯示瀏覽器視窗（預設縮到工作列） |
| `--headless` | 完全不開視窗（有 Cloudflare 的網站通常會直接封鎖） |
| `--profile` | Chrome 使用者資料夾，預設為程式旁的 `chrome_profile`；空字串表示不使用 |
| `--delay` | 慢速模式 / next 模式每章間隔秒數 |
| `--max-pages` / `--append` | next 模式的最大章數 / 附加到既有檔案 |
| `--convert` | 簡轉繁設定：`s2tw` 台灣正體（預設）、`s2twp` 另外轉換成台灣用語（如「軟件」→「軟體」）、`none` 不轉換 |

## 注意事項

- **Chrome 設定檔**：預設在程式旁自動建立 `chrome_profile` 資料夾，不會動到你平常用的 Chrome。同一個設定檔不能同時被兩個 Chrome 使用，所以不要同時執行兩次本程式；出現「無法啟動 Chrome」時，請關閉上次殘留的 Chrome 視窗再試。想沿用舊的設定檔可加 `--profile "路徑"`。
- **暫存與續傳**：已下載的章節存在輸出檔旁的 `.novel_cache/` 資料夾（例如 `.novel_cache/術師手冊_黃金屋.jsonl`），以章節網址辨識。txt 每次都由暫存重新產生；刪掉暫存就會從頭下載。換了輸出檔名（`-o`）會使用不同的暫存。
- **品質檢查**：列出的問題多半是網站本身的錯誤（例如黃金屋第 173 章的內容是第 73 章的重複），可以到網站上確認；若是暫時性錯誤，用 `--start N --end N --refresh` 重新下載。
- **網站速度記錄**：存在程式旁的 `site_rates.json`，刪掉即可重新試探；也可以用 `--rate` 直接指定。
- **人機驗證**：網站跳出 Cloudflare「驗證您是人類」時，請在跳出的瀏覽器視窗中手動勾選，程式會自動繼續。程式不會自動繞過驗證。
- **速度取決於網站限制**：程式會自動找出網站能接受的最快速度。實測：
  - tw.hjwzw.com：每秒約 15～20 頁為上限，整本 1381 章約 2.5 分鐘，100 章約 2 秒。
  - uukanshu.cc：大約每 30 個請求就要求人機驗證，整本 1370 章約需 90 分鐘。
- **網站名稱**：檔名中的網站名稱取自網頁標題（例如「黃金屋中文」→「黃金屋」），取不到時用網域名稱。想自訂檔名請用 `-o`。
- **廣告過濾**：如果有廣告文字沒被濾掉，可以把關鍵字加進程式開頭的 `AD_PATTERNS`。
- **簡轉繁**：會先把內容統一轉成簡體再轉回繁體，連網站原本轉錯的字（如「白發」→「白髮」）也會修正。如果還有沒轉到的字，可以把規則加進程式中的 `FIX_RULES`。「伙食、游泳、天台、倒霉」等是正確的台灣用字，不是簡體。
- **目錄分頁**：目錄被拆成多頁（下拉選單「第 1–100 章」、頁碼、「下一頁」）時會自動抓回其他頁並合併。這個功能尚未在真實網站上驗證，如果章數不對，可以先用 `--list` 確認，或改用 `--mode next`。
- **章名**：小說狂人（czbooks）的章名只有「第N頁」，這是網站本身的設計（按固定長度分頁，網頁上沒有章名）。
- 請只下載你有權閱讀的內容，並尊重網站的使用條款。
