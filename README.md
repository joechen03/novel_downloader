# 通用小說下載器

輸入小說的**目錄頁網址**，自動找出所有章節並下載成 txt 或 EPUB。不針對特定網站撰寫規則，大部分「目錄頁 + 章節頁」結構的小說網站都能直接使用。

## 功能

- **自動判斷目錄**：找出章節連結並依順序排列，自動排除「最新章節」、導覽列、推薦書等雜訊。頁面上有「完整目錄」「查看完整章節目錄」之類的按鈕時會自動點開；給的是只列出最新幾章的書籍介紹頁時，會自動改開「目錄」頁；目錄拆成多頁（頁碼、下拉選單、「第1-100章」這類範圍連結）時會自動抓回其他頁。
- **自動擷取正文**：找出頁面中的正文區塊，過濾常見廣告行，以及正文開頭重複的標題、發布日期、作者資訊。
- **自動刪除每章都有的雜訊行**：一半以上章節都出現的同一行（網站宣傳文字、「(本章完)」等）會在輸出時刪除，不必一個個加進廣告關鍵字。
- **簡轉繁**：用 OpenCC 把簡體字轉成台灣正體，並把 “ ” ‘ ’ 換成「 」『 』。簡體網站也會輸出繁體。
- **輸出 txt / EPUB**：用 `--format` 選擇；EPUB 有章節目錄（有分卷時會依卷分兩層），並自動抓網站上的封面圖片。
- **一章多頁**：章節被拆成 `123.html`、`123_2.html` 時會自動合併。
- **快速模式**：在瀏覽器內同時下載多章，沒有限速的網站幾秒內就能下載完一整本。
- **人機驗證**：遇到 Cloudflare 等驗證時會跳出瀏覽器視窗，讓你手動完成驗證後自動繼續，並自動降速。
- **中斷續傳**：下載中的章節會分批存進暫存，中斷（按 Ctrl+C、當機、關掉視窗）後重新執行同一個指令，會自動略過已下載的章節。連載中的小說之後再執行一次，也只會下載新章節。
- **品質檢查**：下載完會列出可疑的章節（字數過少或過多、和其他章內容重複、章節頁上的章號和目錄不同），方便發現網站錯誤或抓錯頁面。
- **記住網站速度**：被限流的網站會記下穩定的速度，下次直接用這個速度開始，不必重新試探。
- **沒有目錄也能下載**：給章節網址時，會一路點「下一章」往下抓，同樣支援中斷續傳。
- **一次下載多本、一鍵更新連載**：可以一次給多個網址或一個網址清單檔；`--update-all` 會把下載過的書全部更新一次，只抓新章節。
- **進度與預估時間**：下載中會顯示已下載章數與預計還要多久。

## 安裝

需要 Python 3.10 以上，以及已安裝的 Google Chrome。

```bash
pip install -r requirements.txt
```

不需要另外下載 chromedriver（Selenium 會自動處理）。

簡轉繁需要 `opencc`（已包含在 requirements.txt）。如果你的 Python 版本裝不起來，可以改裝純 Python 版 `pip install opencc-python-reimplemented`，用法相同。沒裝的話程式仍可執行，只是不會轉換簡體字（引號仍會轉換）。

## 使用方式

```bash
# 下載整本，存到 downloads/術師手冊_黃金屋.txt
python novel_downloader.py https://tw.hjwzw.com/Book/Chapter/47403

# 輸出 EPUB；--format both 則 txt 和 EPUB 都輸出
python novel_downloader.py https://tw.hjwzw.com/Book/Chapter/47403 --format epub

# 先列出章節清單確認，不下載
python novel_downloader.py https://tw.hjwzw.com/Book/Chapter/47403 --list

# 只下載第 1～100 章，並指定檔名（副檔名會依 --format 自動加上）
python novel_downloader.py https://tw.hjwzw.com/Book/Chapter/47403 --end 100 -o 術師手冊

# 中斷後：重新執行同一個指令即可，已下載的章節會自動略過
python novel_downloader.py https://tw.hjwzw.com/Book/Chapter/47403

# 品質檢查標出第 173 章有問題，重新下載這一章
python novel_downloader.py https://tw.hjwzw.com/Book/Chapter/47403 --start 173 --end 173 --refresh

# 沒有目錄頁：從某一章開始一路抓「下一章」
python novel_downloader.py https://example.com/book/1/1.html --mode next

# 一次下載多本（網址直接接在後面，或寫在文字檔裡，一行一個，# 開頭為註解）
python novel_downloader.py https://tw.hjwzw.com/Book/Chapter/47403 https://ixdzs.tw/read/586712/
python novel_downloader.py -i 書單.txt --format epub

# 更新 downloads/ 裡所有下載過的書（連載中的小說只會抓新章節）
python novel_downloader.py --update-all
```

下載中可以隨時按 **Ctrl+C** 中斷，已下載的章節會保留，並立刻輸出目前的進度。

### 參數一覽

| 參數 | 說明 |
|---|---|
| `url` | 目錄頁網址，可以給多個（`--mode next` 時為起始章節網址） |
| `-i`, `--input` | 從文字檔讀入網址清單（一行一個，`#` 開頭為註解），依序下載 |
| `--update-all [資料夾]` | 更新資料夾（預設 `downloads/`）中所有下載過的書，只下載還沒下載的章節；每本書沿用當初的網址、格式等設定 |
| `-o`, `--output` | 輸出檔名，預設為 `downloads/書名_網站名`；副檔名依 `--format` 自動加上。只能用在單本書 |
| `-f`, `--format` | 輸出格式：`txt`（預設）、`epub`、`both`（兩種都輸出） |
| `--list` | 只列出章節清單，不下載 |
| `--start N` / `--end N` | 下載範圍。輸出檔一律包含**所有已下載的章節**，不只這次的範圍 |
| `--refresh` | 重新下載範圍內的章節（預設會略過已下載的章節） |
| `--reverse` | 目錄由新到舊排列時使用 |
| `--keep-repeated` | 不要自動刪除每章都出現的雜訊行 |
| `--mode auto/toc/next` | `auto` 自動判斷（預設）、`toc` 強制解析目錄、`next` 一路點下一章 |
| `-c`, `--concurrency` | 快速模式同時下載數，預設 8 |
| `--batch-size` | 快速模式每批最多幾章，預設 50；每批完成就存進暫存。有限速時會自動改成每批約 20 秒的量 |
| `-r`, `--rate` | 起始速度（每秒幾頁）。預設沿用上次記錄的速度，沒有記錄則不限；`0` 表示不限。被限流時自動降速，順利時再逐步加速 |
| `--slow` | 改用瀏覽器逐章開啟（需要執行 JavaScript 才有內容的網站使用） |
| `--show` | 下載時顯示瀏覽器視窗（預設縮到工作列） |
| `--headless` | 完全不開視窗（有 Cloudflare 的網站通常會直接封鎖） |
| `--profile` | Chrome 使用者資料夾，預設為程式旁的 `chrome_profile`；空字串表示不使用 |
| `--delay` | 慢速模式 / next 模式每章間隔秒數 |
| `--max-pages` | next 模式最多抓幾章 |
| `--convert` | 簡轉繁設定：`s2tw` 台灣正體（預設）、`s2twp` 另外轉換成台灣用語（如「軟件」→「軟體」）、`none` 不轉換 |

## 注意事項

- **輸出位置**：預設存在程式旁的 `downloads/` 資料夾。用 `-o` 可以指定其他路徑（相對路徑以目前所在資料夾為準）。
- **Chrome 設定檔**：預設在程式旁自動建立 `chrome_profile` 資料夾，不會動到你平常用的 Chrome。程式上次被強制結束、留下佔用這個設定檔的 Chrome 時，下次啟動會自動關掉它們（只會關掉使用 `chrome_profile` 的 Chrome）。不要同時執行兩次本程式。想沿用舊的設定檔可加 `--profile "路徑"`；用自訂設定檔時不會自動關閉殘留的 Chrome。
- **暫存與續傳**：已下載的章節存在輸出檔旁的 `.novel_cache/` 資料夾（例如 `downloads/.novel_cache/術師手冊_黃金屋.jsonl`，旁邊還有記錄網址的 `.book.json` 與封面圖），以章節網址辨識。txt / EPUB 每次都由暫存重新產生；刪掉暫存就會從頭下載。換了輸出檔名（`-o`）會使用不同的暫存。
- **品質檢查**：列出的問題多半是網站本身的錯誤（例如黃金屋第 173、520 章的內容都是第 73 章的重複），可以到網站上確認；若是暫時性錯誤，用 `--start N --end N --refresh` 重新下載。
- **網站速度記錄**：存在程式旁的 `site_rates.json`。只有實際被網站限流過，才會記錄（打 85 折留點餘裕），刪掉即可重新試探；也可以用 `--rate` 直接指定。
- **人機驗證**：網站跳出 Cloudflare「驗證您是人類」時，請在跳出的瀏覽器視窗中手動勾選，程式會自動繼續。程式不會自動繞過驗證。
- **速度取決於網站限制**：程式會自動找出網站能接受的最快速度。實測：
  - tw.hjwzw.com：每秒約 15～20 頁為上限，整本 1381 章約 2.5 分鐘，100 章約 2 秒。
  - uukanshu.cc：大約每 30 個請求就要求人機驗證，整本 1370 章約需 90 分鐘。
- **網站名稱**：檔名中的網站名稱取自網頁標題（例如「黃金屋中文」→「黃金屋」），取不到時用網域名稱。想自訂檔名請用 `-o`。
- **廣告過濾**：如果有廣告文字沒被濾掉，可以把關鍵字加進 `novel/config.py` 的 `AD_PATTERNS`。
- **簡轉繁**：會先把內容統一轉成簡體再轉回繁體，連網站原本轉錯的字（如「白發」→「白髮」）也會修正。如果還有沒轉到的字，可以把規則加進 `novel/converter.py` 的 `FIX_RULES`。「伙食、游泳、天台、倒霉」等是正確的台灣用字，不是簡體。
- **目錄分頁**：目錄被拆成多頁（下拉選單「第 1–100 章」、頁碼、「下一頁」，或目錄首頁只列出「第0000--0100章」這類範圍）時會自動抓回其他頁並合併。範圍目錄已在黃金屋手機版實際驗證（14 頁合併成 1381 章）；頁碼式的分頁目錄還沒找到可以完整測試的網站。如果章數不對，可以先用 `--list` 確認，或改用 `--mode next`。
- **雜訊行**：一半以上章節都出現、至少 4 個字的同一行會被刪除，輸出時會列出刪掉了哪些。短的對話（「嗯。」）不會被刪；如果刪錯了，加 `--keep-repeated`。暫存裡保留原文，加或不加這個參數都不用重新下載。
- **一次下載多本 / 更新**：其中一本失敗（例如網址打錯）會繼續下一本，最後列出結果；按 Ctrl+C 則停止全部。`--update-all` 只認得用這個版本下載過的書（會在暫存資料夾記下網址），之前下載的書請用網址重新執行一次。更新時會下載整本還沒下載的章節，不沿用上次的 `--start` / `--end`。
- **封面與分卷**：封面取自網頁的 `og:image` 或書籍圖片，只在輸出 EPUB 時下載，存在暫存資料夾。分卷依目錄頁上的「第一卷」等標題或章名中的「第X卷」判斷。
- **不能同時執行兩次**：兩個程式會搶同一個 Chrome 設定檔，第二個會直接提示並結束。真的要同時跑，請給第二個 `--profile 其他資料夾`。
- **章名**：小說狂人（czbooks）的章名只有「第N頁」，這是網站本身的設計（按固定長度分頁，網頁上沒有章名）。
- **EPUB 作者**：網頁有標示作者（`og:novel:author` 等）時才會填入，否則顯示「未知」。
- 請只下載你有權閱讀的內容，並尊重網站的使用條款。

## 檔案說明

| 檔案 | 說明 |
|---|---|
| `novel_downloader.py` | 執行入口 |
